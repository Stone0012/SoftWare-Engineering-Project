# 🚀 Project Overview
This project implements a complete software‑engineering lifecycle to improve an app‑review rating prediction system. The system predicts numeric ratings from free‑text user reviews using Azure Machine Learning pipelines. Following the DSC592 project instructions, our focus is on engineering rigor—requirements, architecture, planning, experimentation, documentation, and delivery.

We follow the **OpenUP-style four-phase model**:
- **Inception** — Understand stakeholders, personas, and requirements
- **Elaboration** — Define architecture, risks, and project planning
- **Construction** — Build and improve pipelines through experiments
- **Transition** — Finalize system, documentation, and presentation

All tasks are managed through GitHub Issues and a Project Board.
